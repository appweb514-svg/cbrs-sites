# Conventions

- Interface, erreurs et documentation en français.
- Pas de dépendance de production ajoutée pour les améliorations CMS.
- Réutiliser les slots, boutons, photothèque et droits Payload existants.
- Tester les modifications de schéma sur une base locale jetable, distincte de la production.
- `.codegraph/` contient un index local et reste ignoré par Git.
